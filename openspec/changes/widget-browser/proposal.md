## Why

Cache Studio has no way to browse game widgets.

## What Changes

- Add Widgets to the existing cache tab row.
- List widget IDs and component counts in a paginated table.
- Open a three-pane workspace with component hierarchy, cache-backed preview, and inspector.

Preview edits are temporary. Cache writes and client script execution are outside this change.

## Capabilities

### New Capabilities

- `admin-widget-browser`: Browse and inspect cached widgets.

## Impact

Angular admin Cache Studio. Reuses the existing authenticated reference-table API.
