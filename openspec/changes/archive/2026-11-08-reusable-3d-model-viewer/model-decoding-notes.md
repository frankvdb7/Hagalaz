# Model decoder reference

The revision-742 GameClient selects the newer model format when the final two bytes are `FF FF`; otherwise it selects the legacy format. Both formats must be covered before the geometry task can be marked complete.

For the legacy format, the final 18 bytes hold vertex count, triangle count, texture-triangle count, five attribute flags, and four stream lengths. Vertex coordinates are cumulative deltas, selected by per-vertex bit flags. Deltas use the client signed-smart encoding: one byte minus 64, or two bytes minus 49152. Triangle connectivity uses four opcodes and cumulative signed-smart deltas. Face data includes color, optional shading and texture mapping, priority, alpha, and skin groups. Texture triangles hold three unsigned vertex indices. The client's old-format decoder is `ModelDefinition.method1199`; the newer decoder is `method1201`.

Do not treat the face color of a textured legacy face as its display color: the client moves that value to the texture ID and replaces the color with 127. Preserve the special alpha and mapping semantics until rendering behavior is verified.

Texture PNG output must explicitly use RGBA: ImageSharp retains source RGB/palette metadata and otherwise discards generated cutout alpha. Live texture 8 has 3211 black-key pixels; production PNG conversion preserves all 3211 as transparent. Regression: TextureImageDecoderTests.ToPng_CutoutAlphaSurvivesRgbSourceMetadata.
