# Design
Create one local TypeScript interface per backend DTO under cache/services/dtos, with a barrel for imports. Map C# integers to number, char to string, nullable values to unions, byte[] to base64 string and extra-data values to string|number. Keep full item read and update interfaces separate, explicitly project item update payloads to exclude computed fields. Use generic existing store features to retain DTO types without adding state owners. Shared mutation UI state is a union of actual result DTOs; search/range presentation may use the existing summary shape. No changes to HTTP routes or backend code.
