# Design
Place contracts under Features/Types/Dtos. Extract existing records with unchanged fields into operation-named DTOs. Keep read mapping at existing owners. GetItemDefinitionDto owns response properties and FromItem; UpdateItemDefinitionDto owns stored request fields and ApplyTo; derived properties are response-only. Mutation handlers create their own result DTO; shared persistence only encodes, validates and writes. No callbacks or second persistence path. Arrays and generic SearchDefinitionsDto retain their existing JSON representations. Images and multipart sprite upload remain binary/HTTP streams. Existing tests validate the real routes and DTO JSON; extend the full-field regression to verify derived fields are response-only.
