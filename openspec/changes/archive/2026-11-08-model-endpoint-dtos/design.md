# Design
Use GetModelDto as the shared geometry representation across raw/item/NPC/object models. Extract GetItemModelAppearanceDto preserving computed Available and offsets. Use GetAnimationSequenceDto and GetAnimationFrameDto with AnimationFrameDto, AnimationTransformDto and AnimationSkeletonDto. Map decoder output explicitly at the endpoint boundary. ModelParticleDto contains ParticleEmitterDto instead of a decoder definition. All fields/defaults/nullability and uint color JSON remain unchanged. Add matching local client interfaces under existing admin service DTOs and keep shared renderer interfaces as independent rendering inputs. TextureEndpoints is outside this change.
