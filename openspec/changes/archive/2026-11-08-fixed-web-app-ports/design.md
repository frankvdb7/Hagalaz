# Design
Replace WithHttpEndpoint(targetPort: ...) with WithHttpEndpoint(port: ...) on the two existing JavaScript resources. port is the externally advertised/proxy port; targetPort is internal. Retain env PORT so Aspire injects the allocated internal listener port into existing Angular scripts. Avoid using the same fixed port for proxy and listener. Keep all service references, externally exposed annotations and publishing settings. Test the existing AppHost model without starting resources. Leave the currently running distributed session intact; the new endpoint ports apply on its next restart.

## Verification
AppHost/test projects built and all 5 AppHost model tests passed. WebApplications_AdvertiseFixedPortsWithAllocatedInternalListeners checks each web resource's advertised port, absent fixed target port, proxying and external visibility. Initial isolated build lacked restored assets for the indirectly published Game.Scripts project; explicitly restoring it in the same artifact directory resolved that build setup issue. Existing dependency, game/script nullability and AppHost obsolete-API warnings remain; the changed configuration/test introduces no new warning. Strict OpenSpec validation and git diff --check passed. No current Aspire session was restarted, so new advertised ports apply at its next restart.
