# Design
Extract contracts to Features/Containers/Dtos with its matching namespace. GetContainerDto is the common representation for ordinary and decrypted reads; DecryptContainerDto owns the XTEA request. WriteContainerDto retains base64 data, compression default zero and nullable version. Use byte compression in DTOs and cast only at the cache mapping boundary, preserving the existing numeric JSON representation. No admin consumer uses these routes. Test the actual routes with production cache code and isolated MemoryFileStore; preserve opaque data and reference-table write ownership.
